# 📚 Library Management System (MERN Stack)

A comprehensive digital library solution built using the **MERN stack (MongoDB, Express.js, React.js, Node.js)**.

This application features **dual-role access for Students (Users) and Librarians (Admins)**, providing a seamless experience for managing and consuming library resources.

---

## 🚀 Features

### 👤 For Users
- **Discover Page:** Browse through the complete collection of books
- **Personal Library:** Track issued books and manage returns
- **Favourites:** Save books to a personalized favourites list
- **Audiobooks:** Listen to the integrated audio collection
- **Account Management:** View and edit profile details

### 🛠️ For Admins (Librarians)
- **Admin Dashboard:** Overview of library statistics
- **Book Management:** Full CRUD operations (Create, Read, Update, Delete)
- **User Management:** Monitor and manage user records
- **Issue/Return Control:** Manage book issue and return entries
- **Dashboard Filtering:** Dedicated management-only navigation interface

---

## 🛠️ Tech Stack

**Frontend:** React.js, Bootstrap 5, React Router, Axios  
**Backend:** Node.js, Express.js  
**Database:** MongoDB  
**Authentication:** JWT (JSON Web Tokens) & LocalStorage

## ⚙️ Installation & Setup

### 1. Clone the repository
```bash
git clone https://github.com/Diyapaun/Library-Management-System.git
cd Library-Management-System
```

### 2. Install dependencies
```bash
npm install
cd lms && npm install
cd ../lms_backend && npm install
```

### 3. Run the project
```bash
npm run dev
```

---
